Hi! I originally made this to keep myself from forgetting java but i eventually wanted to share my progress here in the end.


This project revolves around the multiplayer DLC (Butcher Circus) for the game Darkest Dungeon.

It allows players to use modified backgrounds alongside colorgrades, custom themed loading screens, custom themed torches and custom combat music!

Its also possible to configure yourself which colorgrade/loading screen/torch/music to use to a certain background, check my guide to see which keyword to use in which section.




I upload music-less releases (light version) here in this github repository (due to upload size limit).

My drive instead has the latest music release (full version) and additional custom backgrounds (usually from other games)
